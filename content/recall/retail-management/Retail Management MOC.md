# Retail Management: Map of Content

## What this is
Entry point for the Retail Management ESE notes: a node map for every unit, topic nodes with worked examples, and a "Unit N Exam Answers" node per unit. The faculty material is the RM unit slides (Units 1 to 4) and the "RM Notes" file; there are no Unit 5 slides, so Unit 5 is built from your own notes with textbook additions tagged.

**Exam pattern is assumed.** There is no course plan for Retail Management. The pattern is assumed to match Bond Market: 50 marks, Section A 3 x 5, Section B 2 x 10, Section C one compulsory 15-mark case, no phone calculators. Confirm the real pattern and date with the faculty. Numerical practice sits mainly in Units 3 and 4.

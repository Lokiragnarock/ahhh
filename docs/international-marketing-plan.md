# International Marketing notes: plan

Build International Marketing to the Sustainable Finance standard: node notes, a node map per unit, a question bank per unit, and a subject MOC. Folder slug `international-marketing` (label "International Marketing" from default title-casing).

## What the exam is

- No course plan on file yet. Assume the standard Christ BBA ESE: **50 marks, 2 hours.** Section A: 3 of 5 x 5 marks. Section B: 2 of 3 x 10 marks. Section C: one compulsory 15-mark case. Same shape as `buildMock` in `src/lib/paper.ts`.
- Theory-heavy subject: every unit's exam-answers node has a case layout (market entry, mix adaptation, environment analysis).
